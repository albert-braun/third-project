# Aperture Studios

Photography studio landing: header, past work, tools, and footer. Image-first Figma layout in React, with CSS and styled-components.

**Live:** [albert-braun.github.io/third-project](https://albert-braun.github.io/third-project/)

## What it does

- **Photo blocks** — full-width studio imagery and copy
- **Work** — past projects
- **Chrome** — responsive header and footer

**Stack:** React 18 · Vite · styled-components · CSS

## Run locally

```bash
npm install
npm run dev
```
